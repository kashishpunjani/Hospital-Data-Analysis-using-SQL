# Hospital Data Analysis (SQL Project)

## Objective
Analyze hospital data to extract business insights using SQL.

## Dataset
Contains hospital operations data including:
- Hospital name
- Location
- Department
- Patients count
- Doctors count
- Admission & discharge dates
- Medical expenses

## Key Analysis Performed
- Total patients across hospitals
- Department-wise patient load
- Hospital-wise medical expenses
- Average stay duration per department
- City-wise patient distribution
- Monthly expense trends

## SQL Concepts Used
- Aggregations (SUM, AVG, COUNT)
- GROUP BY
- Date calculations
- ORDER BY + LIMIT
- Data summarization

## Outcome
Converted raw hospital data into structured business insights for decision-making.
